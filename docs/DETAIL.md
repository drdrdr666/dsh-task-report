# 任务档案

一次任务交出去以后，最容易丢的不是代码，是这几样：做到哪了、动过什么、还要用户做什么、哪些没验证、这趟到底换来了什么。它们通常只躺在对话正文里，会话一断就归零。

这个插件把它们沉淀成工作区里的 **`.dsh-task/<slug>.md`**：随工作区存活，可提交进仓库，可跨会话读回，也能直接交给下一个人接手。

## 为什么不是“随手写个 markdown”

| | 随手写 markdown | 本插件 |
|---|---|---|
| 结构 | 每次不一样，容易漏项 | 固定十节，缺项在收尾时被点名 |
| 收尾 | 靠自觉 | `close` 校验，缺内容直接拒绝收尾、不写收尾时间 |
| 残留 | 没人检查 | 收尾时自动扫凭据、端口、写死的旧默认值 |
| 读回 | 找文件、猜格式 | `show` / `list` 直接给结构化结果 |
| 跨会话 | 看运气 | 文件在工作区，与 session 无关 |

区别的关键是**收尾门槛**：不填“待用户操作”“未验证项”“已验证/未覆盖范围”，任务就不算结束；工作区里还有没关的调试端口或没删的 token，也一样过不去。

## 工具

| 动作 | 用途 |
|---|---|
| `open` | 建立档案，记录目标（建议用用户原话），并设为当前任务 |
| `update` | 增量补记 |
| `close` | 收尾校验：缺项与残留环境问题会一起返回，且不写入收尾时间 |
| `show` | 读回当前任务的完整档案 |
| `list` | 列出所有任务及阶段与收尾状态 |

## 收尾会拦住哪些情况

### 内容缺项（必须显式交代，没有也要写“无”）

- 目标原话
- 至少一条已完成项，且带验证证据
- `value.did` 与 `value.helped`
- `userActions` 与 `unverified`
- `sideEffects` 结构
- **`coverage.covered` 与 `coverage.uncovered`** —— 说“测试通过”时，必须同时说清它没覆盖什么

### 环境残留（自动扫描，不用你记）

| 检查 | 对应事故 |
|---|---|
| `.gh-token` / `.gh-device.json` 等凭据文件 | 生成了 5 个 token，本地留着一个 |
| 9333 / 9222 / 8899 等端口仍在监听 | 调试端口能让本地任意进程操控浏览器 |
| 代码里写死的旧账号、旧文案 | 复用脚本时把别的项目信息带进来 |

这类问题会被拼成 `副作用自检：…` 一起返回，处理掉才能收尾。

## 档案的十节

1. 目标
2. 已完成（每条带证据）
3. 进行中
4. 阻塞（原因 / 已尝试 / 需要谁动手）
5. 待用户操作（动作 / 为什么 / 不做的后果）
6. 副作用清单
7. 未验证与已知限制（含“已验证范围 / 未覆盖范围”）
8. 决策记录
9. 价值收口（做成了什么 / 对用户的帮助 / 后续可复用）
10. 下次入口

## 副作用为什么分五类

| 类别 | 忘掉的后果 |
|---|---|
| 文件 | 不知道哪些是这次新增的，回滚无从下手 |
| 系统设置 | 改过 hosts / 注册表却没人记得，排查时误导 |
| 进程与端口 | 调试端口、本地代理忘了关，长期暴露 |
| 外部账号 | 在别人仓库里建过东西，所有权不清 |
| 凭据 | token 生成了却不撤销，长期有效权限 |

## 用法

```
task_report(action:"open", slug:"my-task", goal:"用户原话")

task_report(action:"update", patch:{
  phase:"实现",
  done:[{what:"修掉了 X", evidence:"node tests/run.mjs 6 组通过"}],
  coverage:{ covered:["单测 6 组","真图回归"], uncovered:["干净环境安装"] },
  sideEffects:{ processes:["起了本地代理 8899，已关闭"] }
})

task_report(action:"close", patch:{
  userActions:[{action:"重启宿主", why:"进程里仍是旧代码", ifNot:"修复不生效"}],
  unverified:["未在干净环境验证安装"],
  value:{did:"…", helped:"…", reuse:["tools/xxx.mjs 可复用"]},
  sideEffects:{ files:["新增 lib/x.js"] }
})
```

## 限制

- 档案存在**工作区**里，不写入会话日志；换工作区就看不到旧任务。
- 不做自动采集：副作用、待办、证据仍需在过程中通过 `update` 记进去。插件保证结构完整，**不保证内容诚实**。
- 环境自检只看工作区与本地端口，不做远程核对。
- 只记录，不代替验证：`done[].evidence` 是文字，插件不会核对它是否真的跑过。
- 字符串数组（`unverified` / `next`）按值去重。
